# Бинго
Бинго представляет из себя Android приложение, разработанное на языке Kotlin для добавления развлекательного характера в список дел.

Первоначальной целью является привлечение молодежы, которой сложно сконцентрироваться на стандартных списках дел.

Проблему мы решаем путем создания из списка дел игры, где пользователь должен решить бинго на основе тех дел, которые он указал в приложении.

Следуйте этим трем шагам, чтобы начать:

Создайте первую задачу: На главном экране нажмите кнопку "+" и введите "Купить продукты" или "Сделать зарядку".

Сгенерируйте Бинго: Перейдите на вкладку "Бинго" и нажмите кнопку "Создать поле".

Отмечайте и побеждайте: Выполнили задачу? Отметьте её в любом месте (в списке или на поле Бинго)! Ячейка загорится, приближая вас к заветной линии "Бинго!"

## Возможности приложения

1. Умный список задач

Создание, редактирование и удаление задач.
Установка сроков выполнения.
Автоматическая сортировка: невыполненные задачи всегда сверху.

2. Игровое поле Бинго

Случайная генерация сетки 3x3 из ваших актуальных задач.
Автоматическая синхронизация статусов: отметка в списке = отметка в Бинго.
Наглядное выделение выполненных ячеек.

3. Локальное хранение

Все ваши задачи и прогресс сохраняются прямо на телефоне (база данных Room).
Приложение работает полностью без интернета. Ваши данные в безопасности и никуда не передаются.

## Часто задаваемые вопросы (FAQ)
Вопрос: Приложение требует доступ в интернет?
Ответ: Нет. Для работы приложения подключение к сети не требуется.

Вопрос: Что произойдет, если я удалю задачу, которая находится в моей сетке Бинго?
Ответ: Поле Бинго автоматически обновится. Ячейка, где была удаленная задача, либо заполнится другой невыполненной задачей (если есть), либо станет пустой.
